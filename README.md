# odin-recipes
A project for the Odin Project Foundations Course

<h2>📖 Project Overview</h2>
<h5>This project is a simple, multi-page Recipe Website built with semantic HTML5. It provides easy-to-follow cooking guides for classic dishes, including Beef Stroganoff, Lasagna, and Hamburgers.</h5>

<h2>🌟 Key Features</h2>
<h5>Semantic HTML Structure: Uses proper standard elements.

Easy Navigation: Includes home page navigation link structures on each recipe page.

Clear Formatting: Ingredient lists and step-by-step instructions presented in organized unordered and ordered lists.

Visual Appeal: Features high-quality images for each dish.</h5>

<h2>🍽️ Included Recipes</h2>
<h5>Beef Stroganoff: A classic Russian sautéed beef dish with sour cream sauce.

Lasagna: An Italian baked layered pasta dish with meat sauce and cheese.

Hamburger: A staple American sandwich featuring grilled beef patties and custom toppings.</h5>
